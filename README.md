# Simple Calculator in C

A lightweight, command-line calculator written in C. It performs basic arithmetic operations quickly and efficiently.

## 🚀 Features
* **Addition** (`+`)
* **Subtraction** (`-`)
* **Multiplication** (`*`)
* **Division** (`/`)
* Error handling for division by zero.
* User-friendly command-line interface.

## 🛠️ Prerequisites
To run this project, you need a C compiler installed on your system:
* **Windows**: MinGW or Visual Studio
* **macOS**: Xcode Command Line Tools (`gcc` / `clang`)
* **Linux**: GCC (`sudo apt install build-essential`)

## ⚙️ How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd CodeAlpha_Calculator_using_C
   ```

2. **Compile the program:**
   ```bash
   gcc Calculator.c -o calculator
   ```

3. **Execute the program:**
   * **Windows:**
     ```bash
     calculator.exe
     ```
   * **Linux/macOS:**
     ```bash
     ./calculator
     ```

## 💻 Example Usage
```text
Enter first number: 10
Enter an operator (+, -, *, /): *
Enter second number: 5

Result: 10 * 5 = 50
```
